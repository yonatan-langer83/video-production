## One-time droplet setup

```bash
# Node 22, nginx, certbot, pm2
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs nginx certbot python3-certbot-nginx git
npm i -g pm2

mkdir -p /var/www/video-planner
cd /var/www/video-planner
git clone https://github.com/yonatan-langer83/video-production.git .

cp deploy/.env.production.example .env
# PAYLOAD_SECRET is generated by remote-deploy.sh if .env is missing

cp deploy/nginx.videos.kabbalah.co.il.conf /etc/nginx/sites-available/videos.kabbalah.co.il
ln -sf /etc/nginx/sites-available/videos.kabbalah.co.il /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
certbot --nginx -d videos.kabbalah.co.il --non-interactive --agree-tos -m contact@kabbalah.co.il
```

## Deploy updates

From your PC (Windows):

```bat
deploy\deploy-from-windows.bat
```

Or pull on the server:

```bash
cd /var/www/video-planner
git pull
bash deploy/deploy.sh
```

First deploy only (seed admin + import):

```bash
cd /var/www/video-planner
npm run seed
npm run import:kabbalists -- ./data/kabbalists-export.csv
npm run migrate:productions
npm run sync:schema
```
